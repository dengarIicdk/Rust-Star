## 5. Игровые сведения (со страницы описания CurseForge, News/changelog 1.5.0)

Это **описание от автора**, а не результат реверс-инжиниринга. Используется только
для составления каталога функций (docs/FEATURE_PARITY.md), не как ТЗ на код.

Подтверждено из описания: наличие навыков SS-01 Railgun, SS-03 Gungnir,
SS-04 Seven Stars, SS-05 Tesseract, SS-06 Gravitia; предмет-«Stellar Remote»
(пульт); меню навыков по клавише H; катсцены; настройка радиуса/урона слайдерами.
Числовые значения (200-блочный радиус, 1500 макс., 400 блоков, 1440 блоков и т.д.)
— маркетинговое описание, не гарантия точной механики.
